# Visual acceptance target

Primary reference:
`reference/visual-target-inflation-topic.png`

Primary URL:
`/topics/inflation`

Primary viewport:
**1536 × 1024**

The target is not pixel-perfect reproduction of generated text/artifacts. It is structural and aesthetic fidelity.

## Must match strongly

- white/off-white editorial canvas
- slim top header
- brand at top-left
- search control top-right-ish
- left Explore rail
- large central reading surface
- right topic context rail
- serif page title / editorial hierarchy
- sans-serif body and controls
- fine neutral borders/rules
- restrained blue accent
- question rows with chevrons
- 3 chart preview cards in a row at desktop width
- right-rail count blocks and related topics
- bottom breadcrumb/status line is optional; normal breadcrumb placement is acceptable if visually cleaner

## Must not drift toward

- dark dashboards
- glassmorphism
- huge pill buttons
- giant gradients
- excessive border radius
- oversized cards
- dense BI dashboard widgets
- graph-network visualization as the main page
- chat/AI interface styling

## Screenshot review questions

1. Does this look like an economic publication/reference atlas rather than a SaaS app?
2. Is `Inflation` clearly the editorial focus?
3. Can the eye discover Questions → Charts → Related topics naturally?
4. Do the side rails support rather than compete with the main reading surface?
5. Are borders, shadows, and accent color restrained?
6. Does the page feel credible even though chart previews are illustrative?
