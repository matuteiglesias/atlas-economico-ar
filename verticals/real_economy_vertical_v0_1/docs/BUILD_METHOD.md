# Real Economy v0.1 — Build method

The vertical follows the global construction order and the precedent established by Nominal Stabilization and External & Financial Constraint.

1. **Evidence packet.** The May 2026 IMF Argentina report supplies mechanisms, decompositions, and measurement ideas. A bounded 500-headline corpus supplies agenda/vocabulary only. Neither source replaces official measurement truth.
2. **Concepts.** Define only the vocabulary needed by accepted questions; API series names are not concepts.
3. **Typed relations.** Use only the frozen global relation vocabulary. Descriptive co-movement is not causality.
4. **QuestionIntents.** Organize the region around breadth, composition, investment/capacity, domestic demand, sectoral divergence, and bounded cross-region transmission questions.
5. **ReferenceFrames.** Keep only analytically meaningful recent-recovery and longer-run comparison frames.
6. **CanonicalIndicators.** Define stable measurement needs; technical Series binding remains deferred.
7. **DerivedIndicators.** Declare only low-assumption growth-rate transforms. GDP contribution arithmetic is deliberately deferred pending source/accounting validation.
8. **PlotIntents.** Every plot answers at least one accepted question. Cross-region plots may reuse already-owned Nominal/External indicators without duplicating them.
9. **ChartSpecs.** Only a selected subset gets semantic ChartSpecs. No active `figures/specs/` entry is created.
10. **Validation and co-compilation.** The vertical validates internally, compiles as the third semantic vertical, and remains blocked from public child surfaces by `populated: false`.

The build intentionally rejects ontology growth driven backwards from source availability.
