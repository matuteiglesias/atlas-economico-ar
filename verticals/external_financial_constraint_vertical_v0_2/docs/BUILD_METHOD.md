# Build method

Evidence → concepts → typed relations → recurring questions → canonical measurements → derived indicators → plot intents → selected ChartSpecs.

Media is used for agenda/question discovery, not causal truth. The IMF report contributes mechanisms, decompositions,
reference frames, and stress-test questions. Official series will later own measurement truth.

Editorial density is asymmetric by design:
- core Topics: richer `intro`;
- every Question: richer `dek` + `intro`;
- selected Charts: explanatory `intro`;
- Indicators remain compact reference objects.

This adds reading depth without adding new ontology classes.
