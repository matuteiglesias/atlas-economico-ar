# Visual principles v0.1

The target feeling is:

**economic publication + atlas + excellent reference documentation**

Not:
- SaaS dashboard;
- ontology debugger;
- force-directed graph demo;
- card-grid product homepage;
- generic AI aesthetic.

## Density

Use two layers of density:

### Primary reading
- title / dek / intro;
- questions;
- charts;
- human explanations.

### Secondary reference
- indicators;
- relation types;
- counts;
- backlinks;
- technical metadata.

Secondary material may live in a right context rail on wide screens and collapse below/behind disclosure on narrow screens.

## Typography / hierarchy

- Editorial, serious typography.
- Generous reading whitespace.
- Fine rules and restrained borders.
- Small uppercase eyebrows for object type.
- Metadata is compact, not dominant.
- Charts are allowed to become the most visually expressive elements later.

## Human labels

Prefer:
- Questions people ask
- See it in the data
- How we measure it
- Connected ideas
- Used by
- Related topics

Avoid exposing:
- QuestionIntent
- PlotIntent
- CanonicalIndicator
- incoming_edges
- node_distance

## Layout

A three-zone desktop shell is approved as a visual direction:

`Explore navigation | Reading surface | Context rail`

It is not a rigid requirement for every viewport.

No XY semantic-map coordinates or interactive whole-graph layout are part of v0.1.
