# Argentina Economic Atlas — agent operating contract

This repository is a compiled scientific/publication system. Prefer smaller trustworthy public surfaces over more generated objects.

## Read the closest contract first

- Figure / PlotArtifact work: read `figures/AGENTS.md` and `figures/PUBLICATION_QA.md`.
- Web / UX / route / browser-test work: read `web/AGENTS.md`.
- Series work: preserve source authority, provenance, and existing validation contracts.

## Global boundaries

1. Do not change economic meaning to make a chart or page look better.
2. Do not infer source semantics from labels when provider metadata or repository contracts disagree.
3. Do not silently change canonical indicator meaning, source bindings, derived formulas, denominators, frequencies, or time semantics.
4. Do not delete useful measurements because one rendering or route is weak.
5. Prefer quarantine, reference, supersession, or non-publication over misleading publication.
6. Treat generated `site-data/` and PlotArtifacts as compiler outputs unless the local contract explicitly says otherwise.
7. Keep work bounded. One agent run should leave a measurable reduction in curation or UX debt, not open a redesign.

## Default execution shape

Before editing:

- reconstruct the current compiled state from repository evidence;
- identify one bounded queue;
- state the expected observable improvement;
- inspect the actual rendered/public output when the task is visual or experiential.

After editing:

- run the narrowest relevant validators first;
- run the existing full publication/web checks when output or navigation changes;
- inspect the resulting rendered artifact or browser journey, not only source code;
- report what moved from weak/unreviewed to a terminal trustworthy state.

## Escalation rule

Stop and request human judgment when a fix would require a substantive economic interpretation, a new measurement convention, a source-semantic decision, a new derived methodology, or a major information-architecture redesign.
